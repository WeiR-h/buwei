# 权限与隐私

Rinx 管理登录及 SDK 身份。应用参数不能声明本人身份。业务授权单独查看
和确认，绑定账号与有效期；撤销后停止动作，重启不继承授权。每个邀请
和文章发布仍需核对确切预览。

本机保存活动、偏好、操作摘要、原编号、回执和去重记录。活动房间成员
可读取活动快照和业务事件。本版业务事件尚不支持端到端加密，请勿填写
敏感个人信息。正式测试使用本人控制的房间。

模型仅在用户主动请求时调用，填写的需求会发送到 MiniMax。模型不能
直接改队列或绕过确认。调用及 Token 限额不等于人民币扣费上限，实际
扣费以供应商账单为准。

密钥用 Windows DPAPI 保存在资料目录。授权、密钥、会话、数据库、
聊天原文和私人路径不属于公开材料。公开证据使用脱敏摘要和统计，
区分服务端时间与本机采集时间。

删除资料前应关闭并备份。关闭宿主撤销业务授权，不自动删除 Rinx 登录
或业务记录。支持渠道：[Issues](https://github.com/WeiR-h/buwei/issues)。
