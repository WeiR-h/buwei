# 权限与隐私

Rinx 管理本人登录和真实身份。补位单独预览并确认业务权限，授权最长一小时；撤销、账号切换、退出或到期后停止自动同步和发送。重启后重新授权。

新邀请、本人报名和回复、活动卡片分享以及文章发布绑定账号、活动、内容和编号。自动补位另行确认活动、队列规则、发送时段、邀请期限及发送次数上限，规则变化后需重新确认。参与者亲自决定是否接受。

## 数据可见范围

本机保存活动、报名偏好、草稿、操作编号、执行回执和同步记录。活动房间成员可读取活动快照和业务事件；联系人收到卡片时可见时间、地点和当前名额。业务事件使用服务端可读格式，避免填写敏感个人信息。

本人主动请求 AI 功能时，活动安排、目标和报名理解发送填写的需求与补充回答；候补解释、活动问答和小记使用去身份事实，排除账号、姓名、房间编号和活动标题。AI 返回可编辑草稿或已核验事实的引用，执行经过宿主核验。

“主动 AI 分析”另行预览并确认，只发送去身份的类型、时段、人数统计和已确认目标字段，使用本机共享预算。相关事实或目标变化后最多每分钟一次，相同依据复用结果。该授权随业务授权到期，可单独撤销。普通十秒同步不直接触发模型调用，模型不可用时保留规则提示。

个人目标、长期偏好、反馈和任务进展按本人账号保存在独立本机数据库，不写入活动房间快照。推荐只读取本人已接入并核验的补位活动。取消不自动改变长期偏好；“更新长期偏好”需要本人明确选择，支持查看和撤回。

模型密钥使用 Windows DPAPI 加密，同一 Windows 用户才能读取。资料目录与运行程序分开保存；多个入口共享本机模型预算。额度由本机设置控制，实际扣费以 MiniMax 账单为准。

## 备份与恢复

升级前关闭旧版并备份，保留旧目录和入口；有效业务授权不迁移。发送结果不明时保留原编号，在活动记录中核实；不要删除数据库后重新发送。活动创建不明时使用“恢复待核实的活动创建”。

密钥、Rinx 会话、数据库、聊天记录和原始开发记录不上传到公开仓库。向 [Issues](https://github.com/WeiR-h/buwei/issues) 反馈时提供脱敏后的问题步骤。
