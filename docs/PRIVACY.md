# 权限与隐私

Rinx 管理登录及 SDK 身份。应用参数不能声明本人身份。业务授权单独查看
和确认，绑定账号与有效期；撤销后停止动作，重启不继承授权。每个邀请
和文章发布仍需核对确切预览。

本机保存活动、偏好、操作摘要、原编号、回执和去重记录。活动房间成员
可读取活动快照和业务事件。本版业务事件尚不支持端到端加密，请勿填写
敏感个人信息。正式测试使用本人控制的房间。

模型仅在用户主动请求时调用，填写的需求和补充回答会发送到 MiniMax。模型不能
直接改队列或绕过确认。调用及 Token 限额不等于人民币扣费上限，实际
扣费以供应商账单为准。

密钥用 Windows DPAPI 保存在资料目录。授权、密钥、会话、数据库、
聊天原文和私人路径不属于公开材料。公开证据使用脱敏摘要和统计，
区分服务端时间与本机采集时间。

删除资料前应关闭并备份。关闭宿主撤销业务授权，不自动删除 Rinx 登录
或业务记录。支持渠道：[Issues](https://github.com/WeiR-h/buwei/issues)。

## 模型与费用

固定使用 MiniMax-M3（api.minimax.cn）。需求理解只发送本人输入；
匹配说明和小记发送去身份摘要，移除账号、姓名、房间编号及活动标题。
每项建议和草稿都经过结构及业务校验，轮询同步不调用模型。

每资料目录每天最多 20 次、30,000 tokens，每分钟最多 3 次。
显式合成测试入口独立计数，每天最多 80 次、180,000 tokens，仍与应用
共用该资料目录既有预算；测试只接收声明为虚构的案例，不连接 Matrix。
每次 HTTP 尝试（包括结构重试）先预留 0.10 元，每隔离资料目录最多
10 元；失败保留预留。两测试目录合计最多 20 元。预留用于开发控制，
使用量估算与供应商实际扣费分别显示，尚需在供应商账单核对实际扣费。
