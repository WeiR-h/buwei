# 补位 BuWei

评审可从固定 Release 下载作品，并按使用指南启动。宿主、框架和补丁版本见 dependencies.lock.json；源码、构建流程及测试完整提供。
演示覆盖真实输入、独立授权、执行和接收者回复。截图与视频使用虚构活动，隐私处理见隐私说明。
