## 项目说明

活动有人取消时，组织者按候补顺序、可用时段和容量选择下一位。
补位分别记录名额保留、邀请送达、本人接受；参与者用自己的 Rinx
身份报名与回复。每次对外动作先展示确切对象和内容，由本人确认。
发送结果不明时保留原操作编号，重启后核实服务端事件。

MiniMax 通过官方 OctoSense 模型宿主理解需求、解释匹配和生成匿名
活动小记。输出通过结构和业务规则检查，不直接占位或发布。
授权、持久化执行与回执逻辑在两个业务场景中共用 Rust 核心库。

## 材料清单

- 公开仓库、固定依赖清单、源码包及 Windows 两角色运行包。
- 真实双账号及故障验收、干净 Windows 构建和启动记录。
- 约三分钟实际原生界面演示；明确说明截图序列及验收脚本驱动。
- 图标、脱敏截图、SHA-256 清单和可评审核心库贡献补丁。
- 首次运行、隐私、第三方许可、已知限制及更新记录。
