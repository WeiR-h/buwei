## Windows 构建修正

首次干净机器启动先发现图形设备不受支持，随后确认 WARP 设备创建通过
但发布参数覆盖栈配置，实际 PE 仅预留 1 MiB。构建后统一并核验为
16 MiB，仅修改未签名 PE 栈字段及校验和，代码与资源字节保持一致；
Windows 校验和 API 与实际渲染分别核实。诊断 run 37045383161 在干净
Windows 机器通过。v0.1.0 仍需完整源码构建及独立运行环境通过。
