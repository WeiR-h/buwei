## Windows 构建修正

首次干净机器启动先发现图形设备不受支持，随后确认 WARP 设备创建通过
但发布参数覆盖栈配置，实际 PE 仅预留 1 MiB。构建后统一并核验为
16 MiB，仅修改未签名 PE 栈字段及校验和，代码与资源字节保持一致；
Windows 校验和 API 与实际渲染分别核实。诊断 run 37045383161 在干净
Windows 机器通过。完整 v0.1.0 源码构建及独立运行环境均在
[run 37082493252](https://github.com/WeiR-h/buwei/actions/runs/37082493252) 通过。
构建提交为 `4c246b295108131708547562a90a03f25b3568f6`，Rust 1.98.0 MSVC，
Visual Studio 18.10.12217.157、MSVC 14.51.36231。后续文档和证据提交保持
原生源码摘要与二进制不变。演示明确标注为验收脚本驱动真实 SDK 的截图序列，
不是连续人工操作录像。供应商账单、主办方受理和贡献合并没有作为通过项。
