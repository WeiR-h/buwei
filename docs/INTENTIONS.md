# 让补位持续关注我的安排

## 我的目标

组织者先选择本人创建的活动，在“我的目标”填写目标确认人数和检查时间。人数不超过活动容量；已过检查时间的目标会在下一次完整同步后检查。成员填写活动类型、起止日期时间和包括本人在内的同行人数。

可以用一句话生成可编辑草稿。缺少日期、时段或人数时补齐后再确认保存。每张目标卡片显示本人确认的来源，支持修改、暂停、恢复和删除。修改或删除目标会暂停尚未完成的旧任务，保留已有操作和回执。

长期偏好在同一页单独保存。当前目标的明确要求优先；“仅本次”只改目标，“更新长期偏好”才会修改长期记录。反馈可撤回；之后又修改过同一资料时，先查看最新内容再决定如何更改。

## 主动建议

成员可选择“使用我确认的每周安排”，在独立日期范围内按星期、每日时间和同行人数筛选。跨午夜窗口属于开始日，例如周六 23:00–次日 02:00 覆盖周日凌晨。整场活动须在可用窗口内。目标保存采用的偏好快照；之后修改长期偏好时，已有目标需本人重新选择并确认才更新。

组织者的缺口建议显示目标、已确认、保留和待确认人数，并解释本场候补的时间与同行限制。可以继续跟进或选择联系人并预览分享；提示只引用本场已核验报名，个人偏好保持私有。

首页会展示人数缺口、暂时不合适的候补、自动补位暂停、合适活动、待回复邀请、报名结果和时间冲突。卡片附原因、核验依据及更新时间；点击准备下一步。活动状态变化或过期后，旧建议不再使用。

可以处理、忽略、稍后提醒或关闭某类建议。默认北京时间22:00–08:00安静，普通建议每天最多三次桌面提醒；每份待回复邀请提醒一次。安静时段仍更新应用内卡片，主动设置的稍后提醒到时重新检查。

## 跟到结果

“活动记录”显示每个任务的待确认、待回复、待核实、完成或暂停状态。可继续原任务或暂停。确认后的分享、报名和回复仍使用已有执行与回执流程；发送不明时先沿原编号查询。组织者核验“报名已确认”后才显示对应任务结果；实际到场另行反馈。

没有合适候补时，组织者选择联系人并确认分享。个人推荐保留既有候补顺序；只有本场已确认的自动补位规则能够自动邀请。

## 托盘值守

在“账号与设置”主动开启值守后，关闭主窗口会隐藏到Windows托盘。托盘可打开补位、查看待办、暂停并撤销授权、真正退出。暂停、退出、账号变化或授权到期后停止新动作。重启后授权重新确认，并先核实旧操作。

值守要求程序和电脑继续运行；休眠恢复后先核验当前账号、授权和服务端记录。个人推荐的桌面提醒需要值守开启。主动AI分析需另行确认，使用范围见[隐私说明](PRIVACY.md)。

## 下一场

组织者可在目标中确认重复周期和筹备提前量。筹备时间到了，补位准备复制原设置的草稿。新日期、地点和人数重新确认，新活动的成员重新报名。
