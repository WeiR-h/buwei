# 从活动类型开始策划

新建活动时，可以说出需求，也可以打开“更多活动类型”，搜索名称、别名或分类。选中模板后，补位保存一份独立策划稿，填入可编辑的名称、建议人数、参加须知、流程和准备清单。原策划稿保留。

## 活动库

| 分类 | 可选活动 |
| --- | --- |
| 校园活动 | 校园讲座、校园竞赛、校园音乐节、社团招新；观影也可选校园场次 |
| 运动健身 | 羽毛球、篮球、足球、跑步、健身瑜伽 |
| 户外出行 | 徒步、骑行、摄影 |
| 文娱休闲 | 桌游、观影、音乐 |
| 学习交流 | 读书会、工作坊、交流分享 |
| 聚会生活 | 聚餐、亲子活动 |
| 社群共建 | 公益志愿、自定义活动 |

例如，搜索“夜跑”可找到跑步，搜索“手作”可找到工作坊，搜索“户外”可同时看到徒步、骑行和摄影。目录以外的内容使用“自定义活动”，名称、说明和流程由你填写。

## 三步办一场活动

1. **选类型或说需求。**例如：“10 月 24 日下午两点到五点，8 人徒步，在公园南门集合。”AI 会准备草稿并追问缺项；没有模型配置也能选模板填写。
2. **核对策划。**模板人数和流程只是建议。填写完整日期、起止时间、地点和实际人数后，预览并确认创建。场地预约、购票和餐厅订位由组织者自行确认。
3. **选择公开或社群发布。**核对发布范围后分享。成员选择活动，以本人身份确认报名；组织者跟进候补、邀请与最终确认，并可导出名单。

选模板不会创建房间、发送卡片、报名或启用提醒。策划中的提醒节点是可编辑建议；自动补位仍需确认本场授权规则。

讲座、竞赛、观影、音乐节与招新可直接从校园入口开始，填写公开的校园信息，设置报名截止；竞赛另有每份报名人数规则。[校园使用方法](CAMPUS.md)

## 让推荐与本次安排一致

“我的目标”和长期偏好支持活动库中的所有类型，也可以填“不限类型”。例如，目标选择“跑步”时，徒步或篮球不会作为同类活动推荐。推荐还会核对全程可用时间、同行人数和实际名额。

可用中文名称、常用别名或类型编号填写筛选。活动列表、详情、问答依据和组织者 CSV 都会显示对应类型；CSV 保留原列顺序，在末尾增加“活动类型”。

## 人数与版本

每个账号同时接入最多五场活动，每场最多 30 个名额、30 条有效报名；每次同行 1–8 人，按实际参与人数整组计入名额。亲子活动包括陪同成人和孩子，名额不足时整组保留候补排位。

新活动类型从 v0.2.13 验证版起提供，组织者和成员应使用该版或更新版本。羽毛球、桌游、读书会及自定义活动沿用原编号，原报名与操作记录继续读取。活动定位、账号核验、权限确认和回执恢复使用同一套流程。
